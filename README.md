# AI Interview Coach

An AI-powered interview coaching application for internship applications.

## Tech Stack

- **Frontend:** React (Vite), JavaScript
- **Backend:** Node.js, Express, JavaScript
- **Database:** MongoDB

## Project Structure

```
ai-interview-coach/
├── frontend/     # React (Vite) client
└── backend/      # Express API server
```

## Getting Started

> Setup commands and feature implementation are documented in the project plan.
> Run `npm install` in both `frontend/` and `backend/` after scaffolding.

## Scripts (after dependencies are installed)

| Location   | Command           | Description              |
|------------|-------------------|--------------------------|
| `frontend` | `npm run dev`     | Start Vite dev server    |
| `backend`  | `npm run dev`     | Start Express dev server |
